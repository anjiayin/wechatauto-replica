# PRD 群消息总结 2026-11-20（微信客服/商机监测系统）

**产品目标**：为客服/商机团队提供群聊重点回溯能力——基于本地数据库（session.db 直读，无需 UIA 抓屏）与现有 AI 基础设施（复用 AIClient 与 settings 表配置），按「群 + 时间段 + 成员 + 风格 + 自定义提示词」灵活生成结构化总结，并可导出与沉淀，让团队快速掌握群内商机、投诉与待跟进事项。

**前提约束（本次不重复建设）**：
- AI 调用复用现有 analyzer.py 的 AIClient（OpenAI 兼容接口、加密存储、timeout/temperature），token 用量计入现有 ai_usage 表与账单估算。
- 消息数据来自 wechatauto 本地 DB 直读；发送人名称统一走现有取名链（备注 → 群显示名 → 群昵称 → wxid），群昵称依赖 group_cards 学习结果。

## 用户故事

1. **基础总结**：作为客服团队成员，我想选择某个群和一段时间范围，一键生成结构化总结（重要提醒 / 热门话题 / 点评 / 待跟进事项 / 其他讨论 / 结语），这样我不用翻几千条聊天记录就能掌握群内重点。
2. **成员筛选**：作为客服主管，我想在总结时只勾选某些群成员（支持搜索、多选），这样能聚焦关键客户或问题人物的发言，排除刷屏干扰。
3. **风格与提示词**：作为运营人员，我想选择总结风格（全面 / 简洁 / 要点式），并可附加一句自定义说明（如"重点关注价格咨询和售后投诉"），这样同一份聊天记录能产出符合我当前需要的总结。
4. **导出**：作为团队负责人，我想把总结导出为 txt 或带样式的 HTML 文件，这样便于归档、打印或发给未使用系统的同事。
5. **历史总结管理**：作为客服团队成员，我想查看、重新打开、删除过往生成的总结（含当时的群、时间范围、成员筛选等参数），这样总结结果可沉淀复用，不必重复生成。

## 需求池

### P0（首版必须）

1. **总结条件表单**
   - 群选择：下拉选择群（数据来自本地 DB 会话列表，支持按群名搜索）；必选。
   - 时间范围：日期/时间选择器，支持跨天任意范围（不限于"当天 + 小时数"，受本地 DB 数据保留范围限制）；默认今天 0 点至今。
   - 成员筛选：选定群与时间后加载该范围内有发言的成员列表（显示名走取名链，附发言条数），支持搜索、多选、全选/清空；不选 = 全部成员。
   - 风格选择：预置「全面 / 简洁 / 要点式」三种；默认全面。
   - 自定义提示词：可选文本域（≤500 字），作为附加要求拼入提示词（如"重点提取价格相关讨论"）。
2. **生成与展示**
   - 生成前显示实际参与统计（筛选后消息条数、成员数、预估 token 及其占预算比例），消息数为 0 时阻止提交并提示。
   - 调用 AI 生成固定结构总结：重要提醒 / 热门话题 / 点评 / 待跟进事项 / 其他讨论 / 结语（风格影响各节详略，结构不变）。
   - 结果页结构化展示（按小节渲染），显示生成时间、耗时、token 消耗；失败可重试。
   - **token 预算与超限策略（用户可配）**：单次总结的 token 预算支持「按金额（元）」或「按 token 数」两种口径配置，程序内部按现有模型单价自动换算；超出预算后的行为提供两种策略供用户选择——「阻止生成」或「仅取最近 N 条并标注已截断」（N 可配）。配置入口在设置页（SettingsPage 的群消息总结配置区），表单统计行实时显示当前预算、预估 token 与预算占比及当前策略。
3. **导出（txt / html）**
   - 结果页提供导出按钮：txt 为纯文本（含标题、参数摘要、各小节）；HTML 为**标准浅色一套样式**（含打印友好，不做暗色/双套），带内联样式（小节标题、列表、参数表头），可直接浏览器打开/打印。
   - 文件名含群名与时间范围（如 `群消息总结-XX群-20261120.txt`）。
4. **历史总结管理**
   - 每次生成自动保存（总结内容 + 完整参数快照 + token 用量）到新表（如 group_summaries）。
   - group_summaries 纳入设置页统一的数据保留时长管理，默认保留 6 个月；与系统其他数据一致，只提供手动清理，不做自动清理。
   - 历史列表页：按时间倒序，展示群名、时间范围、成员筛选摘要、风格；支持查看详情与删除（二次确认）。
5. **导航入口**：左侧导航新增「群消息总结」入口（分析日志之前），页面内 Tabs：「新建总结 / 历史记录」。

### P1（应做）

6. **定时自动总结**：可配置按群定时生成，**默认每日 18:00 触发一次（每日一次）**，触发时间可调整；支持开启/关闭开关；风格用默认；生成后页面角标/SSE 通知；配置存 settings 表。
7. **历史搜索与筛选**：历史列表支持按群名搜索、按日期筛选。
8. **提示词模板管理**：预置风格之外，支持保存常用自定义提示词为模板（增删、恢复默认），表单中可快速选用。

### P2（可做）

9. **导出扩展**：导出 Markdown / PDF（浏览器打印 HTML 即可满足大部分场景，PDF 视需求）。
10. **多群对比总结**：一次选择多个群，分别生成并排展示。
11. **总结内容回链原文**：总结小节支持点击跳转到对应时间段的原始消息查看（复用现有消息上下文展示能力）。

## UI 设计说明（MUI5 风格）

- **入口**：App.tsx 左侧 Drawer 导航在「分析日志」**之前**新增 `Summarize` 图标 + 「群消息总结」，路由 `/summary`。
- **页面结构**（新页面 `GroupSummary.tsx`）：
  - 顶部 Tabs：`新建总结` | `历史记录`（Badge 显示定时任务新产出数）。
  - **新建 Tab**：
    - 条件表单 Card（纵向排列）：①群选择 Autocomplete（选项显示群名 + 近期消息时间）→ ②时间范围 `DateTimePicker`（起止）→ ③成员多选：选定群后展示 Chip 多选框（`Autocomplete multiple`，选项显示"成员名（N 条）"，顶部含全选/清空、搜索）→ ④风格 `ToggleButtonGroup`（全面/简洁/要点式）→ ⑤自定义提示词 `TextField multiline`（带字数计数、placeholder 示例）。
    - 统计行：提交前实时显示"筛选后共 X 条消息 / Y 位成员，预估 token ≈ Z，占预算 P%（当前策略：阻止生成 / 最近 N 条截断）"；消息为 0 或预估超预算且策略为「阻止生成」时禁用生成按钮并提示；策略与预算可在设置页（SettingsPage 群消息总结配置区）修改，支持按金额（元）或按 token 数两种口径，自动换算。
    - 生成按钮 + Loading 状态（AI 调用通常数秒至数十秒，显示进度提示与取消）。
    - 结果区 Card：小节标题（Typography h6）+ 正文，顶部信息条（生成时间/耗时/token），右上角操作按钮组：`导出 txt` `导出 html` `重新生成`。若按「最近 N 条截断」策略生成，结果区顶部明确标注"已截断：仅统计最近 N 条"。
  - **历史 Tab**：`DataGrid`/List 列表（生成时间、群名、时间范围、成员摘要、风格、token），行点击进入只读详情（同结果区渲染），行内删除按钮（ConfirmDialog 二次确认）。
- **设置页补充**：新增群消息总结配置区——token 预算口径切换（金额/token 数）、预算值、超限策略选择（阻止生成 / 最近 N 条截断 + N 值）、定时自动总结开关与时间（默认 18:00）、group_summaries 保留时长（默认 6 个月，仅手动清理）。
- **失败与边界**：AI 调用失败 Snackbar 提示 + 重试按钮；时间范围内无数据/成员无发言给出明确空态文案。
